# food_energy_grid

Dependencies: 

jupyterlab                4.2.4
numpy                     2.0.1
pandas                    2.2.2
xarray                    2024.6.0
cartopy                   0.23.0
seaborn                   0.13.2

Additionally, the user must have sesame installed, which can be found at this link: https://github.com/A2Faisal/SESAME.

The script can be run by simply running python main.py in an environment with the requisite packages installed.
